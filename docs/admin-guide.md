# Руководство администратора центра

Для администратора учебного центра, без технических подробностей. Установку сервера описывает [deploy.md](deploy.md).

## Первый вход

1. Войдите с логином и временным паролем, которые вам выдали. Система сразу попросит придумать свой пароль: не короче 10 символов, не из списка распространённых.
2. Настройте двухфакторную защиту: отсканируйте QR-код приложением Google Authenticator (или любым другим), введите код.
3. **Сохраните 10 резервных кодов** — распечатайте или запишите. Если телефон потеряется, войти можно будет только с ними или если другой администратор сбросит вам 2FA.
4. В «Настройках» проверьте:
   - название центра, контакты и адрес сайта (он печатается на карточках доступа);
   - логотип;
   - окно редактирования журнала (по умолчанию 7 дней);
   - порог посещаемости.

## Как начать учебный год

Делайте шаги по порядку: каждый следующий опирается на предыдущий.

1. **Справочники** → «Учебные годы»: создайте год, отметьте его текущим, задайте модули (периоды для средних баллов). Шкалу оценок (100, 10 или 5) выбирайте сразу: после первой оценки её не поменять. Там же — предметы, кабинеты, нерабочие дни.
2. **Пользователи**: заведите преподавателей (роль «преподаватель», их предметы). Каждому система покажет временный пароль один раз — передайте его лично.
3. **Группы**: создайте группы года и курсы в каждой (предмет + преподаватель, при необходимости ассистенты).
4. **Импорт**: скачайте шаблон, заполните его учениками (фамилия и имя обязательны, группа — название из шага 3) и загрузите. Система сначала покажет ошибки по строкам. Исправьте их в файле и загрузите снова: пока есть ошибки, не создаётся никто. Когда ошибок нет — «создать учеников».
5. **Карточки доступа**: сразу после импорта нажмите «печать карточек» — лист A4 по 8 карточек с логином, временным паролем и QR-кодом сайта. **Пароли видны только на этой странице**; если её закрыть, останется только сброс пароля в карточке ученика.
6. **Расписание** → «Шаблон недели»: расставьте занятия курсов по дням и кабинетам. Система не даст поставить преподавателя, кабинет или группу в два места сразу. Занятия на 4 недели вперёд создаются сами каждую ночь.
7. В карточке каждого ученика при желании задайте **цели по предметам** в процентах: они появятся пунктиром на графике пробных тестов.

## Каждый день

- **Обзор** — начните день с него:
  - занятия сегодня и незаполненные журналы по преподавателям;
  - ученики ниже порога посещаемости;
  - блокировки входа и отказы в доступе;
  - входы администраторов с новых устройств.
  Каждый блок ведёт к действию.
- **Отмена или перенос занятия**: «Расписание» → занятие → «отменить» или «перенести». Ученики увидят пометку в своём расписании. Запросы преподавателей — в разделе «Запросы».
- **Исправить оценку за пределами окна редактирования** может только администратор, с обязательной причиной — она попадёт в аудит.
- **Оплаты** (раз в месяц): «Оплаты» → «Цены и начисления» → «начислить за месяц». Повторное нажатие ничего не задвоит. Цены групп и скидки учеников действуют со следующего начисления. Оплату принимайте в карточке ученика («Оплаты» → ученик). Ошибочную запись аннулируйте с причиной — удалить её нельзя.
- **Объявления**: для всех, для преподавателей, для учеников или для отдельных групп; закрепите важное и задайте срок показа.

## Частые ситуации

| Ситуация | Что делать |
| --- | --- |
| Ученик забыл пароль | «Пользователи» → ученик → «сбросить пароль». Новый временный пароль покажется один раз; при входе ученик сменит его. |
| «Слишком много попыток» | Блокировка снимается сама через 15 минут (с каждым повтором дольше). Досрочно — «снять блокировку входа» в карточке пользователя. |
| Преподаватель потерял телефон с 2FA | «Пользователи» → преподаватель → «сбросить 2FA», затем «завершить все сеансы». |
| Потерян телефон с приложением | В карточке пользователя — «завершить сеанс» у строки «приложение»; можно ещё сбросить пароль. |
| Ученик ушёл из центра | «Группы» → группа → «исключить» с датой. Оценки и посещаемость сохраняются. Вход закрывает архивация в карточке пользователя. |
| Ученик переходит в другую группу | «Группы» → «перевести» с датой: история остаётся в старой группе, новые занятия — в новой. |
| Ученик или преподаватель переслал кому-то ссылку на календарь | Он сам перевыпускает её в «Профиле» → «Расписание в календаре»: старая ссылка сразу перестаёт работать. Ссылка показывает только расписание, без оценок. |
| Ученик просит интерфейс на узбекском | Переключатель «Язык / Til» — на странице входа и в профиле; выбор запоминается на устройстве. Выгрузки, лента календаря и названия групп и предметов остаются как есть. |
| Ученик не занимался месяц, а начисление уже сделано | Карточка ученика в «Оплатах» → начисление → «аннулировать» с причиной. Повторное начисление за этот месяц его не вернёт. |
| Родитель хочет видеть оценки ребёнка | Карточка ученика → «Родители» → «новый аккаунт» (ФИО подставится из профиля) → «добавить родителя». Логин и временный пароль покажутся один раз; распечатайте карточку доступа. Второму ребёнку того же родителя — «уже есть в системе». |
| Родители просят сводку | Карточка ученика → «Сводка для родителей» → «печать». |
| В обзоре «всплеск отказов в доступе» | Кто-то открывал чужие записи. Посмотрите «Аудит» по этому пользователю и при необходимости завершите его сеансы и сбросьте пароль. |
| Вход администратора с нового устройства, который вы не делали | Сразу: «Активные сеансы» → завершить, смените пароль, попросите другого администратора сбросить вам 2FA. |

## Безопасность

- Опасные действия — смена ролей, сброс 2FA, изменение настроек, выгрузка файлов — требуют повторно ввести пароль, если вы вводили его больше 5 минут назад.
- Выгрузки (XLSX, CSV) содержат персональные данные детей. Не пересылайте их в открытых чатах, храните только в нужном месте.
- Всё, что меняется в журнале, записывается в **аудит** («кто, когда, было → стало, причина»). Записи нельзя изменить или удалить никому, включая администраторов.
- «Настройки» → «Резервные копии» показывает последний ночной бэкап и ежемесячную проверку восстановления. Если там ошибка, сообщите тому, кто обслуживает сервер.
